DELE B1 読解力: 5つの課題に対する戦略

2026年6月更新 · 読書時間14分

読解テストの概要

DELE B1の読解テストは、合計30項目の5つの課題で構成されています。完了するために70分の時間があります。これは試験の中で最も長いテストであり、評価のグループ1に最も多くのポイントをもたらします。

各課題は異なる形式を持ち、異なる読解スキルを評価します。各課題が何を求めているのか、どの戦略を適用するのかをよく理解することは、あなたのスペイン語のレベルと同じくらい重要です。

時間管理: 5つの課題に70分

時間の配分は重要です。すべての課題が同じ努力を必要とするわけではありません。以下は推奨される配分です:

  • 課題1: 12分（短いテキスト、比較的速い）
  • 課題2: 15分（長いテキストと選択肢の質問）
  • 課題3: 15分（テキストと文を関連付ける）
  • 課題4: 15分（空欄のある長いテキスト）
  • 課題5: 10分（文法の選択肢のあるテキスト）
  • 見直し: 3分（すべての回答をマークしたか確認）

時計を持って時間を管理してください。もしある課題に予想以上に時間がかかっている場合は、次の課題に進んで後で戻ってきてください。

課題1: 短いテキストの理解

形式

6つの短いテキスト（広告、通知、標識、メモ、メッセージ）が提示され、それぞれについて3つの選択肢からなる質問に答える必要があります。合計: 6項目。

テキストの種類

  • 仕事やサービスの広告
  • 情報または警告のポスター
  • 短いメモやメッセージ
  • 簡単な指示
  • 活動やイベントのプログラム
  • 観光または商業のパンフレット

戦略

テキストを読む前に、まず質問と選択肢を読んでください。そうすれば、どの情報を探すべきかがわかります。これらのテキストは短いので、答えは通常特定の文にあります。同義語を使ってテキストを言い換えた選択肢には注意してください: それらが正しいことが多いです。

よくある罠

不正解の選択肢には、テキストに出てくる単語が含まれていることが多いですが、選択肢が示唆する意味とは異なります。語彙の一致に惑わされないでください: 完全な意味を読み取ってください。

課題2: 長いテキストの理解

形式

1つの長いテキスト（新聞記事、レポート、インタビューまたは物語）に続いて、各3つの選択肢からなる6つの質問があります。合計: 6項目。

テキストの種類

  • 新聞や雑誌の記事
  • 時事問題に関するレポート
  • 公人へのインタビュー
  • 物語や伝記のテキスト
  • 意見記事

戦略

2回の読みのテクニックを適用します:

  1. 最初の速読（スキミング）: テキスト全体を2-3分で読み、全体のアイデア、テーマ、構造を把握します。
  2. 2回目の選択的読み（スキャニング）: 各質問を読み、該当する段落で特定の情報を探します。質問は通常テキストの順序に従います。

よくある罠

不正解の選択肢は一般的には正しいですが、テキストに基づいていません。質問は常にテキストが言っていることに関係しており、あなたがそのテーマについて知っていることには関係ありません。常にテキスト内の証拠を探してください。

課題3: テキストと文の関連付け

形式

3-4つの短いテキスト（通常は同じテーマについて異なる人々が話している）と文のリストが提示されます。各文を対応するテキストと関連付ける必要があります。余分な文があります（気を散らす要素）。合計: 6項目。

テキストの種類

  • テーマに関する異なる人々の意見
  • 関連する個人的な経験
  • レビューや評価
  • 証言や短いインタビュー

戦略

  1. まずすべての文を読み、各文のキーワードに下線を引きます。
  2. 最初のテキストを読み、その内容に一致する文を探します。
  3. 各テキストで繰り返します。すでに割り当てた文にマークを付けて混乱しないようにします。
  4. 余分な文があることを忘れないでください: すべてが使用されるわけではありません。

よくある罠

気を散らす文には、複数のテキストに部分的に出てくる情報が含まれていますが、どれとも完全には一致しません。文がテキストの完全なアイデアを反映していることを確認してください。単語やフレーズの断片だけではありません。

課題4: 空欄のあるテキスト（テキストの再構築）

形式

6つの断片（文または文）が抜き取られた長いテキストがあります。各断片を正しい空欄に配置する必要があります。余分な断片があります。合計: 6項目。

テキストの種類

  • 情報または普及のための記事
  • 物語のテキスト
  • レポート
  • 説明的なテキスト

戦略

これは最も多くの受験者が難しいと感じる課題です。次のステップに従ってください:

  1. 空欄のあるテキスト全体を読み、全体のテーマと構造を理解します。
  2. 各空欄について、文法的な手がかりに注目してください: 代名詞（何を指しているか？）、接続詞（どのような論理的関係を示しているか？）、動詞の時制（時間的な一貫性を保っているか？）。
  3. 空欄の前後の文を読みます。正しい断片は両方の文と文法的および意味的に合致する必要があります。
  4. 最も明確な空欄から始め、難しいものは最後に残します。

よくある罠

気を散らす断片は、テキストとテーマ的には一貫性がありますが、隣接する文との文法的または論理的な接続に失敗します。選んだ断片が周囲の文と流れるようなテキストを作ることを常に確認してください。

課題5: 文法/語彙の選択肢のあるテキスト

形式

6つの空欄のあるテキストです。各空欄について、3つの選択肢から正しいものを選ぶ必要があります。選択肢は通常、文法的な単語（前置詞、代名詞、接続詞）または語彙的な単語（動詞、名詞）です。合計: 6項目。

テキストの種類

  • 物語のテキスト
  • 短い記事
  • 電子メールや手紙
  • 説明的なテキスト

戦略

  1. まずテキスト全体を読み、全体の文脈を理解します。
  2. 各空欄について、各選択肢を含む文全体を読み、最も自然に聞こえるものを選びます。
  3. コロケーション（スペイン語でよく使われる単語の組み合わせ）に注意してください: "hacer un viaje"（"realizar un viaje"ではなく）、"tomar una decisión"（"coger una decisión"ではなく）。
  4. 2つの選択肢の間で迷った場合は、テキストのレジスタ（フォーマル/インフォーマル）や段落の残りとの一貫性を考えてください。

よくある罠

不正解の選択肢は、スペイン語で存在する単語であり、他の文脈では機能する可能性がありますが、その特定の文脈では機能しません。例えば、"por"と"para"はどちらも有効な前置詞ですが、各文では一つだけが正しいです。

DELE B1のための一般的な読書技術

スキミング（全体の速読）

主なアイデアを把握するために迅速に読むことです。長いテキストの最初の読みに役立ちます。タイトル、サブタイトル、各段落の最初と最後の文に注目してください。

スキャニング（特定の情報を探す）

テキスト全体を読むことなく、具体的なデータを探すことです。必要な情報が何かを知っているとき（質問を読んだ後）に役立ちます。キーワードを探して目を素早く動かしてください。

集中読書

特定の断片を詳細に注意深く読むことです。回答がある段落を見つけたときに、正確なニュアンスを理解する必要があるときに使用します。

未知の語彙を扱う方法

知らない単語に出会うのは普通です。動揺しないでください。これらの戦略を適用してください:

  • 文脈: 不明な単語の周りの単語から意味を推測しようとします。
  • 語根と接頭辞: 多くのスペイン語の単語は他の言語と語根を共有しています。"Impredecible" = im（ない）+ predecir + ible（できる）。
  • 関連性: その単語を理解することが質問に答えるために本当に必要か自問してください。多くの場合、回答は特定の単語に依存しません。
  • 品詞: 名詞、動詞、形容詞など、単語が何であるかを特定します... これにより、正確な意味を知らなくても文中での機能を理解するのに役立ちます。

読解力で避けるべき間違い

  • 単語ごとに読む: 読書が遅くなり、全体像を失います。単語のグループで読んでください。
  • 常に戻る: 最初の読みを信頼してください。質問が特に要求しない限り、段落に戻らないでください。
  • 「良さそうな」最初の選択肢を選ぶ: 決定する前に常に3つの選択肢を読みます。時には最初の選択肢が正しいように見えますが、3番目を読むまでそう思わないことがあります。
  • 自分の知識で回答する: 答えは常にテキストにあります。あなたがそのテーマについて知っていることは関係ありません。
  • 回答を転記しない: 公式の回答用紙に回答を転記することを確認してください。ノートにマークした回答は採点されません。
