DELE B1のキーワード — 例を含む必須リスト

2026年6月更新 · 読書時間12分

DELE B1に必要な語彙はどのくらいですか？

CEFRのB1レベルでは、約3,000〜4,000語のアクティブな語彙が必要です。これは、終わりのないリストを暗記しなければならないという意味ではありません。スペイン語を学んでいる時間が長ければ、多くの単語はすでに知っているでしょう。重要なのは、試験で頻繁に出現するテーマ別の語彙をマスターすることです。

以下に、DELE B1の最も一般的なテーマに基づいて整理された語彙と、使用文脈を思い出すのに役立つ例文を紹介します。

旅行と交通

このテーマは、読解とリスニングのテストで常に出現します。

  • 宿泊 — "3ヶ月前に宿泊を予約しました。"
  • 手荷物 — "格安航空券では手荷物は1つだけ持ち込めます。"
  • 乗り継ぎ — "フライトはマドリードに到着する前にリスボンで乗り継ぎます。"
  • ハイシーズン/ローシーズン — "ローシーズンでは価格が大幅に下がります。"
  • クレームをする — "ホテルが写真と一致しなかったので、クレームをしなければなりませんでした。"
  • キャンセルする / 延期する — "嵐のためにフライトがキャンセルされ、翌日に延期されました。"
  • 目的地 — "バルセロナはヨーロッパで最も人気のある目的地の一つです。"
  • 往復切符 — "往復切符は別々の2枚の切符よりも安くなります。"
  • 遅延 — "電車は20分遅れて到着しました。"
  • レンタルする — "海岸を巡るために車をレンタルすることにしました。"

健康とウェルビーイング

リスニング（医療相談、健康アドバイス）でよく出るテーマです。

  • 医療予約 — "火曜日の10時に医療予約があります。"
  • 処方箋 — "医者が抗生物質の処方箋をくれました。"
  • 症状 — "最も一般的な症状は発熱と頭痛です。"
  • 緊急 — "痛みが止まらなかったので、緊急に行きました。"
  • 健康を保つ — "健康を保つために週に3回運動しています。"
  • バランスの取れた食事 — "バランスの取れた食事は健康にとって重要です。"
  • 気分が悪くなる — "船に乗ると気分が悪くなります。"
  • 回復する — "インフルエンザから回復するのに2週間かかりました。"
  • 予防する — "治療するよりも予防する方が良いです。"
  • ウェルビーイング — "ヨガは身体的および精神的なウェルビーイングに寄与します。"

仕事と職業生活

読解（求人広告、ビジネスメール）や作文で出現します。

  • 職を申し込む — "ホテルの受付の職を申し込みました。"
  • 履歴書 / CV — "いくつかの会社に履歴書を送りました。"
  • 仕事の面接 — "仕事の面接は思ったよりも簡単でした。"
  • 契約（期間限定/無期限） — "6ヶ月の期間限定契約を提案されました。"
  • フルタイム/パートタイム — "自由な時間を持つためにパートタイムを希望します。"
  • 給料 / サラリー — "給料はあまり高くありませんが、条件は良いです。"
  • 同僚 — "私の同僚はとても親切です。"
  • 会議 — "3時に上司との会議があります。"
  • 締切 — "プロジェクトの提出期限は金曜日です。"
  • 職務経験 — "最低2年の職務経験が求められます。"

教育と訓練

  • 登録 — "コースの登録料は200ユーロです。"
  • 奨学金 — "海外で学ぶための奨学金を得ました。"
  • 科目 — "私の好きな科目は美術史です。"
  • 合格する / 不合格になる — "数学以外のすべての科目に合格しました。"
  • 成績 — "最終試験で良い成績を取りました。"
  • 訓練 — "会社は従業員に継続的な訓練を提供しています。"
  • 大学の学位 — "マドリードでジャーナリズムの学位を取得しました。"
  • 宿題 — "子供たちは毎日宿題が多すぎます。"
  • ノート — "昨日の授業のノートを貸してくれませんか？"
  • 学位 / ディプロマ — "その職には大学の学位が必要です。"

日常生活と家庭

  • 引っ越す — "先月、より大きなアパートに引っ越しました。"
  • 家賃 / 住宅ローン — "家賃はここ数年で大幅に上昇しました。"
  • 隣人 — "私の隣人は夜にとても騒がしいです。"
  • 家電製品 — "洗濯機は私が最も多く使う家電製品です。"
  • リサイクルする — "私の街ではプラスチック、ガラス、紙をリサイクルしています。"
  • 買い物をする — "土曜日にスーパーマーケットで買い物をします。"
  • 費用 — "管理費は家賃に含まれています。"
  • 故障 — "配管に故障があるので、配管工に電話しました。"
  • 共同生活 — "ルームメイトとの共同生活は必ずしも簡単ではありません。"
  • 近所 — "私は中心部の近くの静かな近所に住んでいます。"

メディアとテクノロジー

  • ソーシャルメディア — "私はソーシャルメディアにあまりにも多くの時間を費やしています。"
  • 投稿する / 共有する — "彼は旅行の写真をプロフィールに投稿しました。"
  • サブスクリプション — "私はシリーズのプラットフォームにサブスクリプションを持っています。"
  • ダウンロードする / インストールする — "アプリをダウンロードしましたが、インストールできません。"
  • パスワード — "メールのパスワードを忘れました。"
  • 更新する — "携帯電話のオペレーティングシステムを更新する必要があります。"
  • ニュース / プレス — "毎朝インターネットでニュースを読みます。"
  • インタビュー — "テレビでとても興味深いインタビューを見ました。"
  • 広告 — "ウェブサイトには広告が多すぎます。"
  • オンライン / 対面 — "コースはオンラインまたは対面で受講できます。"

DELE B1の一般的な偽友達

偽友達とは、あなたの言語の単語に似ているが、スペイン語では異なる意味を持つ単語です。B1にとって最も危険なものは以下の通りです：

  • actualmente = 今、現在（NO "actually" = 実際には）
  • realizar = 行う、実行する（NO "realize" = 気づく）
  • asistir = 行く、出席する（NO "assist" = 助ける）
  • éxito = ポジティブな結果（NO "exit" = 出口）
  • sensible = 感情が豊かな（NO "sensible" = 賢明な）
  • embarazada = 赤ちゃんを待っている（NO "embarrassed" = 恥ずかしい）
  • constipado = 風邪（NO "constipated" = 便秘）
  • largo = 長い（NO "large" = 大きい）

語彙を記憶するためのヒント

1. 文脈の中で単語を学ぶ

孤立した単語を暗記しないでください。常に文や状況の中で単語を学びましょう。"乗り継ぎ"は"私のフライトはパリで乗り継ぎます"を思い出すと、単に"乗り継ぎ = stopover"を暗記するよりも意味があります。

2. スペースドリピティションシステムを使用する

Ankiのようなフラッシュカードアプリは、忘れる直前に単語を表示するアルゴリズムを使用しています。このシステムで語彙を復習するために、毎日15〜20分を費やしてください。

3. 単語のファミリーでグループ化する

関連する単語を一緒に学びましょう：仕事 → 働く → 労働者 → 労働。これにより、効率的に語彙が増えます。

4. 個人的な関連付けを作る

新しい単語を自分の経験と結びつけましょう。"引っ越す"を学ぶときは、最後の引っ越しを思い出してください。感情的なつながりが語彙をより強固にします。

5. 毎日スペイン語を読んだり聞いたりする

言語に常に触れることが、自然に語彙を習得する最良の方法です。記事を読み、ポッドキャストを聞き、シリーズを見てください。見つけた新しい単語をメモし、後で調べてください。

6. 積極的に練習する

単語を認識するだけでは不十分です：それを使えるようにする必要があります。新しい単語を使って文を書き、会話で使用し、DELEの練習テキストに統合してください。

DELE B1のために設計されたインタラクティブな演習で語彙を広げましょう。
