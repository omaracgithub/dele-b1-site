DELE B1とDELE A2：違いとどちらを選ぶべきか

2026年6月更新 · 読了時間9分

両レベルの概要

DELE A2とDELE B1は、共通ヨーロッパ言語参照枠（CEFR）の2つの連続したレベルですが、その間の距離は多くの受験者が期待するよりも大きいです。正しいレベルを選ぶことで、時間、お金、フラストレーションを節約できます。

A2は、簡単で日常的な状況でコミュニケーションができる基本的なユーザーに相当します。一方、B1は、日常生活で発生するほとんどの状況に対処でき、意見を表現し、経験を語ることができる独立したユーザーを認定します。

試験の構造の違い

総所要時間

  • DELE A2：約2時間45分
  • DELE B1：約3時間25分（口頭試験を除く）

読解力

A2では、テキストは短く直接的です：広告、ポスター、メニュー、短いメール。B1では、新聞記事、より長い情報テキスト、正式な文書に直面します。違いは長さだけでなく、文法的および語彙的な複雑さにもあります。

リスニング力

A2の音声は遅く、明確な間隔と限られた語彙を持っています。B1では、速度が自然な話し方に近づき、話者は異なるアクセントを持ち、テーマはより多様です（ニュース、インタビュー、電話会話）。

ライティング力

A2では、非常に具体的なテーマについて70-80語のテキストを求められます（自分の家を描写する、日常生活を語る）。B1では、100-150語のテキストで議論、意見、より複雑な構造が求められます。

スピーキング力

A2では、口頭のやり取りはガイドされ、予測可能です。B1では、会話を維持し、予期しない質問に反応し、ある程度流暢に自分の意見を表現できる必要があります。

文法と語彙の飛躍

A2の文法

  • 現在形（規則動詞と不規則動詞）
  • 基本的な完了形と不定形
  • 「ir a + 不定詞」を使った未来形
  • 基本的な肯定命令形
  • 簡単な比較級と最上級
  • 直接目的語代名詞

B1の追加文法

  • 未完了過去形と不定形との対比
  • 単純未来形と条件法
  • 接続法現在形（願望、意見、評価）
  • 否定命令形
  • 条件文（タイプ1と2）
  • 基本的な間接話法
  • 間接目的語代名詞とその組み合わせ
  • 接続詞（しかし、それゆえ、たとえ）

語彙

A2は、家族、買い物、交通、食べ物などの即時のテーマに焦点を当てた約1,500-2,000語の語彙を扱います。B1は、語彙を3,000-4,000語に拡大し、健康、環境、技術、教育、時事問題などのテーマを含みます。

スペイン国籍を取得するために必要なレベルは？

スペイン国籍を申請するための公式な最低要件はA2レベルです。ただし、重要なニュアンスがあります：

  • DELE A2は、言語知識の法的要件を満たすのに十分です
  • DELE A2に加えて、CCSE試験（スペインの憲法的および社会文化的知識）に合格する必要があります
  • DELE B1以上を取得している場合、文化的内容を含む特定の試験で取得した場合はCCSE試験が免除されます
  • 多くの弁護士は、B1を推奨しています。なぜなら、より高い言語統合を示すからです

もしあなたの唯一の目的が国籍であり、スペイン語のレベルが基本的であれば、A2が最も迅速な選択です。すでに中級レベルを持っているか、長期的により有用な証明書を望む場合は、B1がより良い投資です。

A2を飛ばしてB1に直接進むのはいつか？

A2を経ずにB1に直接進むことは完全に可能であり、多くの場合推奨されます。次の条件に当てはまる場合は、B1に直接進むことを検討してください：

  • 定期的に1年以上スペイン語を学んでいる
  • 大きな困難なく日常会話を維持できる
  • 親しみのあるテーマに関するテキストや音声の一般的なアイデアを理解できる
  • 過去形（不定形、未完了、完了）を知っている
  • スペイン語圏の国に住んでいるか、住んでいたことがある

もしあなたの実際のレベルがすでにB1に近いのであれば、A2に時間とお金を費やす意味はありません。DELE A2はB1を受験するための前提条件ではありません。

必要な準備時間

DELE A2の場合

ゼロから始める場合、A2レベルに到達するには約200-250時間の学習が必要です。すでに基礎がある場合（例えば、A1レベルのコースを修了している場合）、1日1-2時間の学習で2-3ヶ月で試験の準備ができます。

DELE B1の場合

ゼロから始める場合、B1には約400-500時間の累積が必要です。すでにA2レベルが確立されている場合、B1に到達するために150-200時間の追加学習が必要です。これは、集中的な準備で3-4ヶ月（1日2-3時間）または中程度のペースで5-6ヶ月（1日1-1.5時間）に相当します。

準備を加速する要因

  • 母国語（ポルトガル語、イタリア語、フランス語を話す人はより早く進歩します）
  • 言語浸透（スペイン語圏の環境に住むこと）
  • 他の言語の経験
  • ネイティブスピーカーとの定期的な練習
  • DELE形式に特化した教材の使用

コストとロジスティクス

スペインにおけるDELE A2の価格は約112ユーロ、B1は約130ユーロです（2026年の価格）。コストの違いは最小限であり、したがって、あなたのレベルが許すなら、直接B1に進む方が効率的です。

両方の試験は同じ試験日程と試験センターで提供されます。世界中のインスティトゥト・セルバンテスの認定センターで登録できます。

私たちの推奨

A2とB1の間で迷っている場合は、次の質問を自問してください：

  1. 簡単な新聞記事をスペイン語で理解できますか？ → もしできるなら、B1を目指してください
  2. 100語以上のメールを書いて自分の意見を表現できますか？ → もしできるなら、B1です
  3. スペイン語の映画やシリーズをスペイン語の字幕で理解できますか？ → もしできるなら、B1です
  4. 私の主な目的は国籍だけで急いでいますか？ → その場合、A2がより実用的かもしれません

迷った場合は、レベルテストを受けるか、B1の模擬試験を試してみてください。リーディングとリスニングで50％以上の得点を取得できれば、数ヶ月でB1の準備をするための十分な基礎があります。

実際のDELE B1模擬試験で練習し、現在のレベルを確認してください。
