DELE B1のリスニング理解のためのアドバイス — タスクごとに

2026年6月更新 · 読了時間11分

試験の概要

DELE B1のリスニング理解試験は約40分間で、5つのタスクから成り、合計30項目があります。各オーディオは2回再生され、必要な情報を把握するための2回の機会が与えられます。

この試験はグループ2の一部で（口頭表現とともに）、合格するためにはグループ内で最低60％が必要です。リスニング理解は多くの受験者にとって最も難しい試験ですが、適切な戦略を用いることでパフォーマンスを大幅に向上させることができます。

タスク1: 短いメッセージの主旨を理解する

形式

6つの短く独立したメッセージ（ボイスメール、アナウンス、通知）を聞きます。それぞれについて、3つの選択肢（A、B、C）の中から正しい回答を選ぶ必要があります。合計6項目です。

期待すること

  • 各メッセージは20〜30秒
  • 日常的なコンテキスト：約束、計画変更、指示
  • メッセージごとに1人の話者
  • 明瞭な発音での中程度の速度

戦略

  1. 聞く前に選択肢を読んでください。 各オーディオの前に数秒間あります。その時間を使って3つの選択肢を読み、メッセージの内容を予測します。
  2. 重要な情報を特定します。 質問は通常、誰が電話をかけているのか、なぜ、何を求めているのか、いつまたはどこであるかに関するものです。
  3. 気をつけて、気を散らす要素に注意してください。 オーディオは3つの選択肢の情報を言及するかもしれませんが、質問に正しく答えるのは1つだけです。
  4. 最初の聞き取りで回答を選びます。 2回目で確認または修正します。

一般的な罠

  • 話者が計画を述べ、その後変更する：正しい回答は最終的な計画です
  • 複数の時間や日付が言及される：最終的なものに注意してください
  • 似た音の単語ですが、意味が異なる

タスク2: 会話の主旨を特定する

形式

2人の間の6つの短い対話を聞きます。それぞれについて、3つの選択肢の中から正しい回答を選ぶ必要があります。合計6項目です。

期待すること

  • 30〜40秒の会話
  • 日常的な状況：店で、仕事で、友人同士
  • 短いターンの2人の話者
  • 口語的な言語と基本的なイディオム

戦略

  1. 話者の関係を特定します。 彼らは友人、同僚、顧客と販売者ですか？これにより文脈を理解するのに役立ちます。
  2. トーンに注意を払います。 彼らは同意していますか、議論していますか、交渉していますか？トーンは正しい回答に関する手がかりを提供します。
  3. 結論を探します。 多くの質問は、彼らが何をすることに決めたのか、何を考えているのか、次に何をするのかに関するものです。
  4. 二次的な詳細に気を散らされないでください。 会話の主旨に集中してください。

一般的な罠

  • 一方の話者が何かを提案し、もう一方がそれを拒否する：回答は最終的に彼らが合意することです
  • 混乱を招く口語表現：「¡Qué va！」（=いいえ）、「Ya te digo」（=同意します）
  • 文字通りの意味を変える皮肉やサルカズム

タスク3: 長いテキストから特定の情報を抽出する

形式

インタビューまたは長い会話（2〜3分）を聞きます。オーディオの特定の詳細に関する6つの選択肢の質問に答える必要があります。

期待すること

  • 前のタスクよりも長い連続したテキスト
  • 一般的にラジオのインタビューまたは長い会話
  • さまざまなテーマ：個人的な経験、意見、計画
  • 情報の密度が高い

戦略

  1. 最初の聞き取りの前にすべての質問を読みます。 これは重要です。どの情報を探しているかを知ることで、関連する情報をフィルタリングできます。
  2. 質問はオーディオの順序に従います。 質問3に答えるとき、質問4の情報はその後に来ます。戻らないでください。
  3. 簡潔なメモを取ります。 聞いたキーワード、数字、名前を書き留めます。完全な文ではなく。
  4. 最初の聞き取り：できる限り答えます。 2回目の聞き取り：完成させて確認します。

一般的な罠

  • インタビュー対象者が何かを言い、その後訂正する：正しい回答は訂正です
  • 正しいように見える情報ですが、項目が尋ねていることに正確には答えていない
  • パラフレーズ：正しい回答はオーディオの言葉とは異なる単語を使用しています

タスク4: テキストを文に関連付ける

形式

同じ一般的なテーマについて異なる人々が話す6つの短いモノローグを聞きます。それぞれの人をリストの文と関連付ける必要があります（人よりも文が多いので、いくつかは余ります）。

期待すること

  • 6人の異なる人がそれぞれ20〜30秒話す
  • すべてが同じテーマについて異なる視点から話す
  • 6人に対して9つの文があります（3つの文は気を散らすものです）
  • 各文は1回だけ使用されます

戦略

  1. 聞く前にすべての文を読みます。 各文のキーワードに下線を引いて、すぐに特定できるようにします。
  2. 各話者の主旨を探します。 詳細に迷わないでください：彼らの主な意見や経験は何ですか？
  3. 割り当てるにつれて文を除外します。 これにより、次の話者の選択肢が減ります。
  4. 似たような文に注意してください。 それらの違いを注意深く読みます。

一般的な罠

  • わずかに異なる2つの文（肯定的vs否定的、過去vs現在）
  • 話者が気を散らす文の何かを言及しますが、彼らの主なアイデアは別のものに対応します
  • 同じアイデアを表現するための異なる語彙（パラフレーズ）

タスク5: 指示や説明を理解する

形式

情報モノローグ（説明、指示、プレゼンテーション）を聞きます。提示された情報に関する6つの選択肢の質問に答える必要があります。

期待すること

  • 1人の話者による2〜3分のテキスト
  • 情報的または指示的なトーン
  • テーマ：サービスの説明、使用方法の指示、活動のプレゼンテーション
  • 論理的に整理された情報（時間順、カテゴリ別）

戦略

  1. モノローグの構造を特定します。 ステップごと、カテゴリごと、時間順に整理されていますか？これにより、各回答がどこにあるかを予測するのに役立ちます。
  2. 数字、日付、具体的なデータに注意を払います。 質問は通常、事実に基づく情報に焦点を当てています。
  3. 一般的な情報と特定の情報を区別します。 不正解の選択肢は通常、一般化やオーディオの別の部分の詳細です。
  4. 答えられなかった項目については2回目の聞き取りを使用します。 すでに情報がどこにあるかを知っているので、集中できます。

一般的な罠

  • 条件や例外付きで言及されるデータ
  • オーディオによれば真実ですが、特定の質問には正確には答えていない情報
  • 推奨されることと義務であることの混乱

準備時間の使い方

各タスクの前に、質問と選択肢を読むための数秒があります。この時間は貴重です。以下のように使いましょう：

  1. 質問を読みます（選択肢だけでなく）どの情報を探すべきかを知るために
  2. 選択肢のキーワードに下線を引きます
  3. 必要な情報の種類を予測します（数字、場所、意見、行動）
  4. 関連付ける文がある場合（タスク4）、似ているものの違いを特定します

リスニング理解を向上させるための一般的なアドバイス

  • 毎日スペイン語を聞いてください： ポッドキャスト、ニュース、シリーズ、歌。継続的な露出は代替不可能です。
  • アクセントを変えてください： DELEにはスペインとラテンアメリカの話者が含まれる可能性があります。
  • アクティブリスニングを実践してください： スペイン語をバックグラウンドで流さず、注意深く聞き、聞いたことを要約しようとします。
  • すべてを理解しないことに慣れてください： 試験では、すべての単語を理解する必要はなく、尋ねられた情報だけを理解すればよいです。
  • ディクテーションを行います： 短いフレーズを聞いて書き取ります。これにより音を区別する能力が向上します。
