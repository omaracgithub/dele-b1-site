DELE B1 書き言葉の表現：例と戦略

2026年6月更新 · 読了時間10分

書き言葉の試験の構造

DELE B1の書き言葉とインタラクションの試験は60分間で、2つの課題から成り立っています。これは、読解と共にグループ1の一部であり、合格するにはグループ内で最低60％が必要です。

両方の課題に時間を自由に配分できますが、良い戦略は課題1に25分、課題2に30分を割り当て、最後の5分を見直しに使うことです。

課題1：手紙または電子メール

何を求められていますか？

刺激（広告、受け取ったメール、提示された状況）に応じて、100〜120語のテキストを作成する必要があります。テキストは次のいずれかである可能性があります：

  • 正式な手紙または電子メール（企業、機関、教師宛て）
  • 非公式な手紙または電子メール（友人、同僚宛て）
  • フォーラムやソーシャルネットワークでのメッセージ

問題文は常にレジスタ（正式または非公式）を示し、テキストに含めるべきポイントを提供します。

問題文の例（正式）

"あなたは自分の街でスペイン料理のコースの広告を見ました。訓練センターにメールを書いて、スケジュールと価格についての情報を求め、事前の経験が必要かどうかを尋ね、あなたの空き時間を示してください。"

問題文の例（非公式）

"友人のカルロスがあなたに手紙を書いて、あなたの街に引っ越すことを伝えています。彼に返信してください：その知らせに喜びを示し、引っ越しの手伝いを申し出て、住むための地区を提案し、その理由を説明してください。"

課題1の推奨構造

  1. 挨拶：正式（"拝啓"）または非公式（"こんにちは、カルロス！"）
  2. 導入：メッセージの理由を文脈に置く一文
  3. 展開：問題文のすべてのポイントに触れる（2〜3の短い段落）
  4. 締め：レジスタに適した別れの文
  5. 署名：あなたの名前

課題1のための便利なフレーズ

正式なレジスタ：

  • "...に関してお書きしています。"
  • "...についての情報を求めるためにお伺いします。"
  • "...についてお知らせいただければ幸いです。"
  • "お返事をお待ちしております。"
  • "心からのご挨拶を申し上げます。"

非公式なレジスタ：

  • "あなたのメッセージを受け取って嬉しいです！"
  • "...のために書いています。"
  • "...したらどう？"
  • "またすぐに会えることを願っています。"
  • "大きなハグを。"

課題2：記事、エッセイ、またはブログ投稿

何を求められていますか？

130〜150語のテキストを作成する必要があります。次のいずれかである可能性があります：

  • 雑誌や新聞のための意見記事
  • ブログ投稿
  • 体験を語る物語的テキスト
  • 立場を擁護する論証的テキスト

問題文は、あなたが展開すべき文脈とポイントを提供します。

問題文の例

"あなたのスペイン語学校の雑誌が学生に「大都市に住む方が小さな町に住むより良いのか？」というテーマで記事を書くように求めています。各選択肢の利点と欠点、あなたの個人的な経験、意見、結論を含めて記事を書いてください。"

課題2の推奨構造

  1. タイトル：短く、テーマに関連したもの（オプションですが推奨）
  2. 導入（1〜2文）：テーマを提示し、注意を引く
  3. 展開（2〜3段落）：問題文のポイントを例や意見を交えて展開する
  4. 結論（1〜2文）：あなたの立場を要約するか、テキストを締める

重要な接続詞と表現

スピーチを整理するために

  • 第一に / 第二に / 最後に
  • 一方では...他方では...
  • まず始めに / 次に / 最後に
  • に関して / に関しては

意見を表現するために

  • 私の意見では / 私の視点から
  • 私は...と思います / 私は...だと思います
  • 私は...を確信しています
  • 個人的には、私は...だと考えています

アイデアを対比するために

  • しかし / それにもかかわらず
  • たとえ / ...にもかかわらず
  • その反対に
  • 代わりに

情報を追加するために

  • さらに / また / 同様に
  • さらに / 実際に
  • だけでなく...も...

例を挙げるために

  • たとえば / 例えば
  • つまり / すなわち
  • 具体的には / 具体的に言うと

結論を述べるために

  • 結論として / 要約すると
  • 結論として / 最終的に
  • 前述のすべてから

評価基準

試験官はあなたのテキストを次の基準に基づいて評価します：

  1. 適合性：問題文の要求を満たしていますか？正しいレジスタを使用していますか？フォーマットを守っていますか？
  2. 一貫性と結束：テキストは論理的な構造を持っていますか？接続詞を使用していますか？段落は適切に整理されていますか？
  3. 文法の正確さ：動詞の時制、合致、構造を正しく使用していますか？
  4. 語彙の範囲：あなたの語彙は多様で、B1レベルに適していますか？

完璧なテキストを書く必要はありません。試験官はB1レベルの誤りを期待しています。重要なのは、明確にコミュニケーションを取り、さまざまな構造を使用し、問題文のすべてのポイントを満たすことです。

避けるべき一般的な誤り

フォーマットの誤り

  • 単語数を守らない（大幅に少ないまたは多い）
  • 同じテキスト内で正式と非公式のレジスタを混ぜる
  • 手紙/メールで挨拶や別れの言葉を忘れる
  • 問題文が要求するすべてのポイントを含めない

よくある文法の誤り

  • ser/estarの混乱："Estoy de acuerdo"（"soy de acuerdo"ではない）
  • por/paraの誤用："Gracias por tu ayuda"対"Estudio para aprobar"
  • 性の一致："La problema" → "El problema"
  • 物語における過去時制の混乱
  • 接続法の誤用または完全に避ける

内容の誤り

  • 単語数に達するために同じアイデアを異なる言葉で繰り返す
  • 提案されたテーマから逸脱する
  • 求められたときに個人的な意見を述べない
  • あまりにも長くて混乱を招く文を書く

試験当日の実用的なアドバイス

  1. 問題文を2回読み、含めるべきポイントに下線を引く
  2. 書く前に簡単なスケッチを作成する（1〜2分）
  3. 書いている間に単語数を数えて、超えたり不足したりしないようにする
  4. 修正の余地を残す：可能であれば行間を空けて書く
  5. 最後に5分を確保して、明らかな誤りを見直し修正する
  6. 単語を思い出せない場合は、同義語を使うか、別の方法でアイデアを説明する

修正された演習と回答モデルを使って書き言葉の表現を練習しましょう。
