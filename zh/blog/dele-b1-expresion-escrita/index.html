DELE B1 写作表达：示例和策略

更新于2026年6月 · 阅读时间10分钟

写作表达测试结构

DELE B1的写作和互动表达测试持续60分钟，由两个任务组成。它与阅读理解一起属于第1组，您需要在该组中获得至少60%的分数才能通过。

您可以自由分配时间给两个任务，但一个好的策略是将25分钟用于任务1，将30分钟用于任务2，最后留出5分钟进行复习。

任务1：信件或电子邮件

他们要求你做什么？

您必须撰写一篇100到120字的文本，以回应一个刺激（广告、收到的电子邮件、提出的情况）。文本可以是：

  • 一封正式的信件或电子邮件（给公司、机构、老师）
  • 一封非正式的信件或电子邮件（给朋友、同事）
  • 论坛或社交网络上的消息

题目总是会指示您使用的语体（正式或非正式），并给出您必须在文本中包含的要点。

示例题目（正式）

"您在您所在城市看到了一则关于西班牙烹饪课程的广告。写一封电子邮件给培训中心，要求：询问时间和价格，问是否需要先前经验，说明您的可用性。”

示例题目（非正式）

"您的朋友卡洛斯写信告诉您他将搬到您的城市。回复他：表达您对这个消息的喜悦，提供搬家的帮助，建议他一个居住的社区，并解释原因。”

任务1的推荐结构

  1. 问候：正式（“尊敬的先生/女士：”）或非正式（“你好，卡洛斯！”）
  2. 引言：一句话来说明消息的原因
  3. 发展：涵盖题目中的所有要点（2-3个简短段落）
  4. 结束：适合语体的告别语
  5. 签名：您的名字

任务1的实用短语

正式语体：

  • “我写信是关于...”
  • “我向您询问有关...的信息。”
  • “我将非常感谢您告知我...”
  • “我期待您的回复。”
  • “祝好。”

非正式语体：

  • “收到你的消息真高兴！”
  • “我写信是因为...”
  • “你觉得如果...怎么样？”
  • “希望很快见到你。”
  • “给你一个大大的拥抱。”

任务2：文章、论文或博客条目

他们要求你做什么？

您必须撰写一篇130到150字的文本。可以是：

  • 一篇杂志或报纸的评论文章
  • 一篇博客条目
  • 叙述性文本（讲述一个经历）
  • 论证性文本（捍卫一个立场）

题目会给您提供背景和必须发展的要点。

示例题目

"在您的西班牙学校杂志上，要求学生写一篇关于主题：“住在大城市更好还是住在小镇更好？”的文章。写下您的文章，包括：每个选项的优缺点，您的个人经历，您的观点和结论。”

任务2的推荐结构

  1. 标题：简短且与主题相关（可选但推荐）
  2. 引言（1-2句）：介绍主题并吸引注意
  3. 发展（2-3段）：用例子和观点发展题目中的要点
  4. 结论（1-2句）：总结您的立场或结束文本

连接词和基本表达

用于组织论述

  • 首先 / 其次 / 最后
  • 一方面...另一方面...
  • 首先 / 继续 / 最后
  • 关于 / 就...而言

用于表达观点

  • 在我看来 / 从我的角度来看
  • 我认为 / 我觉得 / 我觉得
  • 我坚信
  • 就我个人而言，我认为

用于对比观点

  • 然而 / 尽管如此
  • 虽然 / 尽管
  • 相反
  • 而是

用于添加信息

  • 此外 / 也 / 同样
  • 甚至 / 事实上
  • 不仅...而且...

用于举例

  • 例如 / 比如
  • 也就是说 / 换句话说
  • 具体来说 / 具体地

用于总结

  • 总之 / 总结
  • 为了总结 / 最终
  • 基于以上所有

评估标准

考官根据以下标准评估您的文本：

  1. 适当性：您是否符合题目要求？您使用了正确的语体吗？您遵守了格式吗？
  2. 连贯性和一致性：文本是否具有逻辑结构？您使用了连接词吗？段落是否组织良好？
  3. 语法正确性：您是否正确使用了动词时态、配合和结构？
  4. 词汇范围：您的词汇是否丰富且适合B1水平？

您不需要写出完美的文本。考官期待B1水平的错误。重要的是您能够清晰地表达，使用多样的结构，并满足题目的所有要点。

常见错误及避免方法

格式错误

  • 不遵守字数（写得太少或太多）
  • 在同一文本中混合正式和非正式语体
  • 在信件/电子邮件中忘记问候或告别
  • 未包含题目要求的所有要点

常见语法错误

  • 混淆ser/estar：“Estoy de acuerdo”（而不是“soy de acuerdo”）
  • por/para使用不当：“Gracias por tu ayuda”与“Estudio para aprobar”
  • 性别一致性：“La problema” → “El problema”
  • 叙述中过去时的混淆
  • 虚拟式使用不当或完全避免

内容错误

  • 用不同的词重复相同的想法以达到字数要求
  • 偏离所提议的主题
  • 在要求时不表达个人观点
  • 写出过长且混乱的句子

考试当天的实用建议

  1. 仔细阅读题目两遍，并划出您必须包含的要点
  2. 在写作前快速做一个大纲（1-2分钟）
  3. 在写作时计算字数，以免超出或不足
  4. 留出修改的空间：如果可能的话，行间留出空隙
  5. 最后留出5分钟重读并纠正明显错误
  6. 如果您想不起一个词，可以使用同义词或用其他方式解释想法

通过纠正的练习和答案模型来练习写作表达。
